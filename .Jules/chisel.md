## 2025-03-09 - [EditModeService Payload Refactoring]
**Learning:** Replaced unstructured dictionary payloads (`dict[str, object]`) in `EditModeService` event handlers with explicitly typed Pydantic DTOs (`RegionSelectPayload`, `RegionDragPayload`, `RegionNudgePayload`). This structural enhancement improves stack traceability, removes fragile `dict.get()` manual validations, and delegates parsing boundaries to robust Pydantic models. Also identified and corrected Python 2 era `except ExceptionA, ExceptionB:` tuple masking syntax across multiple UI files.
**Action:** When evaluating GUI and internal service events, explicitly model action payloads as Pydantic models and parse via `.model_validate()` rather than passing untyped dictionaries to system handlers.
