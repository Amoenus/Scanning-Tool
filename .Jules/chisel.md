## 2024-05-15 - [Refactored EditModeService to use typed DTOs]
**Learning:** The UI configuration layer for edit mode relied on unstructured dictionaries (`dict[str, int]`) for passing region payloads, necessitating manual field parsing and lacking boundary validation.
**Action:** Created `RegionDragPayload` and `RegionSelectPayload` DTOs (Pydantic models) to strictly type the data passed across system boundaries. Used `.model_validate` for immediate deserialization in handlers, removing raw dictionary manipulations from the service domain logic.
